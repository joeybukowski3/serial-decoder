Locate the label first, then decode age or research the replacement path.

Quick Start

Most labels are on a door frame, inside a compartment, behind an access panel, or on the rating plate. Once you find the model number and serial number, use the serial decoder if you have the serial, or jump to Smart Lookup if you only have a model number or product description.

Refrigerators

  • Check the inside wall of the fresh-food compartment
  • Look behind the crisper drawers
  • Inspect the side wall near the door seal
  • Check the rear service label or kick plate if needed

FAQ

Model and serial number location FAQ

What is the difference between a model number and a serial number?
The model number identifies the product line or configuration. The serial number identifies your specific unit and is usually what manufacturers encode with date information. If you have both, keep both handy.
Which number do I need for appliance age lookup?
For the best date result, use the serial number. If you only have a model number, Smart Lookup can still help estimate age and identify likely replacements.
What if the label is worn off or unreadable?
Check the rear panel, original receipt, owner manual, installation paperwork, or a second tag behind an access panel. If the serial is unreadable, run Smart Lookup with the model number and a short description.
Do refrigerators, washers, dryers, and HVAC units all use the same label location?
No. Refrigerators are often inside the compartment, dishwashers usually place the tag on the open-door frame, laundry appliances use the door/lid frame or rear console, and HVAC units use a metal rating plate on the cabinet.
