# 2026-05-19

- Fixed a Rheem decoder bug triggered by serial `RHLNQ15143648`.
- Root cause: the `waterHeaters` Rheem decoder accepted any first 4 characters as `MMYY`, so HVAC-like serials beginning with letters were misread as `month=RH` and `year=LN`, which surfaced as the bad `20LN` result.
- Change made in `decoder-data.js`: Rheem Style 1 now requires a numeric `MMYY` start. If that pattern is not present, the decoder can fall back to an embedded `WWYY` block such as `Q1514` -> week 15, 2014.
- Added regression coverage in `tests/decoder-regressions.test.mjs` for `RHLNQ15143648` and confirmed all decoder regressions pass.
