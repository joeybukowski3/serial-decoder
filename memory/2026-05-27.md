# 2026-05-27

- Fixed American Water Heater / A.O. Smith-family numeric `YYWW` serial decoding for late-1990s serials.
- Root cause: A.O. Smith-family water-heater numeric decoders used `2000 + YY` and rejected future years, so `9948125186` became 2099 and fell into the UI incomplete/fallback path instead of 1999 week 48.
- Added shared `decodeAOSmithFamilyNumericYYWW` helper: validates week 01-53, maps future 20xx values back to 19xx, and returns `decodeStyle: Numeric YYWW`.
- Added alias normalization so `American Water Heater` and `American Water Heater Company` both resolve to `american_water_heater_company`.
- Added regression tests for `9948125186`, alias routing, `00/01/99` edge years, malformed length, and invalid week codes.
