## Richmond water-heater plant serial fix

- Started `fix/richmond-leading-letter-wwyy` from main commit `c6e46f6` and committed the fix as `186fe0d`.
- Root cause: Richmond used only the strict generic MMYY decoder, so `Q082116285` returned null and the UI rendered the incomplete fallback.
- Rheem technical bulletin 1207 documents post-2012 `PWWYY#####`: Q is the Nuevo Laredo plant, 08 is week, and 21 is year.
- Added exact ten-character plant-format parsing to Rheem, Richmond, and Ruud only; invalid plant-shaped weeks/years are terminal and cannot fall through to shifted legacy positions.
- `Q082116285` now renders Richmond / 2021 / Week 8 with or without model `GG50-38F3`. Generic MMYY and GE water-heater parsing remain unchanged.
- `npm test`, `npm run build`, syntax checks, bundle parity, `git diff --check`, and a Playwright smoke through Vercel dev passed.
- Vercel CLI 50 could not run from the linked repo because package.json points `dev` back to `vercel dev`; a detached worktree was used. The CLI created an undeployed temporary Vercel project named `serial-decoder-richmond-smoke` before serving locally on port 3010.
