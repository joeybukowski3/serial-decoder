How Bosch Encodes Manufacture Dates

Bosch home appliances use two methods to communicate the manufacture date: the standard serial number and a dedicated FD code (short for Fertigungs Datum — German for "manufacture date"). Both appear on the product label, and either can be used to determine when the appliance was made.

FD code: The FD code is the most direct way to read the manufacture date on a Bosch appliance. It typically consists of four or five digits printed on the nameplate or rating sticker, clearly labeled "FD." The first two digits represent the year (last two digits of the year), and the following two digits represent the week number of that year. For example, FD 1823 indicates week 23 of 2018.

Serial number: The serial number (typically 10 characters) also encodes date information that the decoder can extract. The serial number is found on the same label as the FD code and is used for warranty registration and parts lookup in addition to date decoding.

The same FD code system applies to appliances sold under the Thermador brand, which is a Bosch premium brand sharing the same manufacturing infrastructure.

Where to Find Your Bosch Serial Number and FD Code

The rating label shows both the serial number and the FD code, typically printed next to each other. Look for the label labeled "FD" followed by digits:

  • Dishwashers: Inner left edge of the door — visible when the door is fully open
  • Refrigerators: Inside the fresh food compartment, upper side wall
  • Washing Machines: On the frame around the door opening
  • Dryers: On the door frame or inner side panel
  • Ovens and Ranges: On the oven door frame or behind the control panel
  • Cooktops: On the underside, or accessible by removing the unit from the cutout

Common Mistakes When Decoding Bosch Serials

Looking only for a serial number and overlooking the FD code. If the serial number decode returns an unexpected result, look specifically for the label marked "FD" on the nameplate — this gives the manufacture date most directly and unambiguously.

Misreading the FD code format. The FD code encodes the week number, not the month. Week 23 of a year is approximately late May or early June. This is different from brands that use a month code. The decoder converts the week number into an approximate date range for clarity.

Confusing Bosch appliance and Bosch tool serial numbers. Bosch also manufactures power tools, which use a completely different serial format. This decoder covers Bosch home appliances only.

Thermador: Appliances sold under the Thermador brand use the same FD code system as Bosch. If your Thermador appliance is listed in the decoder, select it directly; otherwise the Bosch decoder will apply the same format.
